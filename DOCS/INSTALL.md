# ⚙️ Installation & Run Guide

## Requirements
- Java 17+
- PaperMC Server (1.21.11)
- Minecraft Client

## Step 1: Setup Server
1. Download PaperMC
2. Create a server folder
3. Run:
   java -jar server.jar
4. Accept EULA

## Step 2: Install Plugin
1. Copy MiningChain.jar
2. Paste into /plugins folder

## Step 3: Run
java -jar server.jar

Server console should show:
[MiningChain] enabled!
